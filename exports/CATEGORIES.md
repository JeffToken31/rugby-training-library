# Exercices par compétence et forme de jeu

Une fiche peut apparaître dans plusieurs catégories : son identifiant reste unique. Les sommes par catégorie ne s’additionnent pas pour compter les exercices.

Classement éditorial proposé, sans validation coach. † = description insuffisante, classement provisoire. L’absence d’un tag ne prouve pas l’absence d’une compétence. Aucun niveau de contact n’est déduit.
